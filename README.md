## المصدر المرجعي

`library/` يحفظ الحزمة1.0.0 بملفاتها الـ924 دون تغيير، مع بيان البصمات الأصلي. الموقع الجديد يقرأ تلك الملفات ويعرضها ويربط تنزيلاتها مباشرة. تغيير مصدر قديم يتطلب إصدارًا جديدًا وفحصًا وتحديث الفهرس؛ لا تعدّل النسخة المحفوظة دون توثيق.

المصادر الأساسية للموقع هي قوالب HTML داخل `site-src/`، و`assets/site.css` و`assets/site.js`، وإعدادات `site.config.json`. الصفحات في الجذر والفهارس داخل `data/` ناتج البناء. لا توجد حزم واجهة خارجية أو مكتبات JavaScript مطلوبة لتصفح الموقع.

## تشغيل محلي

```sh
python3 scripts/build.py
python3 scripts/check.py
python3 scripts/serve.py
```

افتح العنوان الذي يظهر. يتطلب البناء والفحص Python3.9 أو أحدث فقط. أدوات إعادة تصدير الحزم داخل `library/06_ENGINE_HANDOFF` منفصلة واختيارية، ولها تبعياتها الموثقة.

## النشر

GitHub Pages ينشر المجلد الناتج من `scripts/prepare_site.py` عبر `.github/workflows/pages.yml`. المسارات نسبية وتعمل تحت `/dolaby-design-library/`. إعداد المصدر في Settings → Pages هو GitHub Actions. لا يحتاج الموقع مفاتيح خدمات أو متغيرات أسرار.

## النطاق

الموقع مكتبة تصميم تفاعلية. النموذج المضمّن يستخدم بيانات مصطنعة وحالة جلسة محلية. لا محرك AI إنتاجي أو حسابات أو قاعدة بيانات أو شراء فعلي. المصادر المحلية HTML/CSS/JS/SVG/JSON، مع PDF وPNG/JPG. لم تُنشأ ملفات Figma/Canva أصلية أو نموذج3D. فحوص الإتاحة والمنصات محدودة كما في الأدلة.

الخطوط مرفقة برخصهاOFL؛ سجلات المصادر والحقوق داخل `library/05_QA`. إتاحة المستودع للقراءة ليست ادعاء ترخيص عام لكل الأصول.
