## محرك الواجهة

يفسر app.js معاملات screen وlang في الرابط، ويبني الشاشة المناسبة، ثم يستقبل أحداث التنقل والأزرار والنماذج. يستخدم History API للتنقل، وحالة في ذاكرة العرض للحفظ التجريبي والموافقات والحذف وتبديل قطعة المثال. إعادة التحميل تعيد الحالة إلى الأصل.

الاقتراحات تكوينات مصممة مسبقًا. الوصف والمناسبة مدخلات في مسار العرض؛ تغييرهما لا يشغّل خوارزمية تنسيق. شاشة الحساب تمثيل تجريبي، وشاشات الإدارة لا تطبق أمن صلاحيات حقيقيًا. موافقة التفضيلات تعرض تأكيدًا محليًا؛ لا ترسل إعدادات إلى خادم.

P1: البداية ← مناسبة اليوم ← وصف/صورة اختيارية ← تأكيد القطعة ← توضيح ← مثال جاهز ← الإطلالة. طلب الحساب يظهر عند الحفظ. P2 يعرض قطعة مكملة وانتقالًا تجريبيًا إلى متجر دون تنفيذ شراء. P3 يعرض التحكم بالموافقات وحذف قطعة المثال، مع الإلغاء والفشل وإعادة المحاولة. P4 ينتهي باهتمام تاجر؛ P5 يعرض إدارة بيانات مصطنعة.

صورة الواجهة اختيارية، بصيغة PNG أو JPG وحتى 5MB، وتستخدم ObjectURL محليًا. لا يوجد رفع إلى خدمة تحليل صور. تعريفات الكيانات السبعة داخل microcopy-and-demo-data هي عقد تصميم للتنفيذ اللاحق، وليست قاعدة بيانات أو واجهة API منفّذة.

## محرك الحركة

بعد تحميل الخط تُقاس Do وLaby فعليًا. يحدّث توقيت واحد موضع الحلقة وقناع الكشف وقناع استرجاع اللاحقة. تظل Do مستقلة عن قناع اللاحقة. يمتد المشهد 4.8 ثانية؛ يبدأ ظهور الشخصية عند 3.05 ثانية، قبل اكتمال الاسترجاع عند 3.7. أزرار التشغيل والإيقاف والتخطي والمعاينة الزمنية موجودة. مواضع الحركة الداخلية LTR في اللغتين، ويتغير موضع العرض العام فقط.

التوقيت اليدوي متاح عبر ?t=3.2 مثلًا. المعاينة الزمنية تمثل حركة علامة، ولا تشير إلى معالجة AI. الحالة الثابتة الكاملة هي الافتراضية. اختُبرت نقاط زمنية وأزرار محددة؛ اختبار تفضيل تقليل الحركة في نظام التشغيل لم يُنفّذ.

## محرك القوالب والحفظ

يفصل templates.js المحتوى عن render.js الذي يبني العناصر المتجهية والنصية، وعن styles.css الذي يحدد القياس والتكوين. تختار معاملات id وlang وmode القالب. wrappers الخاصة بالقوالب والكاروسيل تضبط SOCIAL_CONFIG ثم تستخدم المحرك نفسه؛ ليست صورًا مسطحة تتظاهر بأنها مصادر تصميم.

في المحرر يمكن تعديل النص مباشرة واستبدال أول رسم بصورة PNG/JPG/WebP حتى 10MB. تُقرأ الصورة محليًا وتُضمّن في النسخة المحفوظة. حفظ HTML ينشئ لقطة مصدر ثابتة، يزيل الأدوات والسكربتات ويحافظ على النص القابل للتحرير. ضع الملف المحفوظ داخل 04_SOCIAL_KIT. إعادة فتحه اختُبرت فعلًا. لا يولّد الحفظ صورة نشر تلقائيًا؛ استخدم التصدير بعد مراجعة التعديل.

## حركة المحتوى الاجتماعي

مصدر الافتتاحية والخاتمة موجود في ../04_SOCIAL_KIT/motion/index.html. يستخدم مشهدًا رأسيًا صامتًا مدته 4 ثوانٍ، مع التشغيل والإعادة والتخطي واختيار المشهد ومعامل توقيت للمعاينة. هذا مصدر ويب قابل للتحرير؛ لم يُنتج ملف فيديو أو مسار صوتي.

## إعادة التصدير للمطور أو المصمم

الأدوات اختيارية؛ جميع الأصول الحالية جاهزة. من هذا المجلد:

```sh
npm install
npx playwright install chromium
npm run smoke
npm run export
```

تعتمد الأدوات على Playwright 1.62.1 وSharp 0.35.5، وهما الإصداران المحليان المستخدمان للاختبار. يتطلب التشغيل Node.js 20.9 أو أحدث، مع Chromium الخاص بـPlaywright. استخدم DOLABY_CHROMIUM_PATH لاختيار نسخة Chromium محلية إذا كانت مثبتة لديك. التثبيت أعلاه عمل تنفّذه عند الحاجة؛ لم تُثبّت الأدوات على أي جهاز آخر ضمن المهمة.

الكتابة بعد الاختيار تكون مثل: npm run export -- --kit ui أو npm run export -- --kit social.

تكتب الأداة في _REGENERATED_EXPORTS بجذر الحزمة، وتحافظ على المصادر والتصديرات المسلّمة. يدعم --kit الاختيارات all وbrand وui وsocial، و--output مجلدًا منفصلًا. العينة --smoke تجرّب هاتفًا عربيًا، وواجهة إنجليزية، وملفين اجتماعيين، وPDF الكتاب وبعض أصول الهوية. لا تعني نتيجتها نجاح تصدير كامل جديد بعد كل تعديل. export-report.json يسجل ما أُنتج في التشغيل الفعلي.

## مزامنة كتالوج المكونات

component-catalog.json هو كتالوج البيانات المرجعي، وcatalog-data.js رفيق مشتق لتشغيل المعرض من ملف محلي. بعد تحرير JSON، استخدم npm run sync:catalog لتحديث الرفيق؛ npm run check:catalog يفحص التطابق دون كتابة. لا يعيد ذلك بناء شاشات المنتج تلقائيًا.

## فحص سلامة التسليم

```sh
python3 tools/verify-package.py
```

الخيار --archive يقبل مسار ZIP لفحص نسخه الداخلية أيضًا. تعمل أداة الفحص بمكتبة Python القياسية، وتقارن الملفات بالبصمات المسلّمة. بعد تعديلك مصدرًا، ظهور Changed متوقع؛ هذا يكشف التعديل ولا يعني تلقائيًا أن التصميم معطوب. احتفظ بالأصل وبنسخة عمل منفصلة.
