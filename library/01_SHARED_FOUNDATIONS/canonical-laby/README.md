# Laby / لابي — المصدر المتجهي

LABY-MASTER-001 · v1.0.0 · DESIGN_RESOLVED. رسم أصلي قابل للتحرير أنشئ لهذه الحزمة؛ لا توجد صورة كاملة مضمّنة في أي SVG.

المناظر الستة: front، side، back، three-quarter، standing، seated. توجد ست وضعيات للمحتوى داخل poses، وإحدى عشرة دراسة حالة داخل states. جميعها مشتقة من نفس مولّد الأجزاء في build_brand.py، وتشارك لغة الشكل والألوان والنواة.

النواة في الواجهة الأمامية 18/12؛ الحلقة ثنائية الأبعاد سوداء مسطحة. الجانب يُظهر إسقاطًا مسطحًا ضيقًا، وليس حلقة معدنية. الجلوس رسم مستقل لا سحق لنسخة الوقوف. لا تنعكس هيئة الاسم DoLaby أبدًا مع اتجاه الواجهة.

طبقات المصدر: feet، arms، body، eyes، flat-nucleus. يمكن تغيير كل جزء منفصلًا في محرر SVG. الجسم وحده يستخدم تدرجًا لؤلؤيًا؛ لا تنقل التدرج إلى الحلقة. النسخة الصغيرة مستقلة وتستعمل تفاصيل أقل وعيونًا أكبر نسبيًا.

التسمية والوضعية لا تثبتان حدثًا في المنتج: لا تعرض processing إلا عند معالجة فعلية أو محاكاة مصنفة؛ لا تعرض success قبل حفظ مؤكد؛ input نص وليس استماعًا. ملف states.json يربط الحالات بالمشغلات.

النموذج ثلاثي الأبعاد والأصل المتحرك 3D: DEFERRED. البيانات الهندسية تصف الرسم المنفذ، ولا تدّعي أنها قياسات لصورة المرجع أو ملف 3D.
