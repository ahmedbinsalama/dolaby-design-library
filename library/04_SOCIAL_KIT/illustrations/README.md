# Individual renderer garment illustrations

These three standalone SVGs contain the same editable paths used in master/render.js. Change fills or paths in the SVG source. They are original illustrated objects, not product photographs or live catalog records. Outfit compositions in the templates combine these objects. PNG derivatives at widths 128 and 512 are supplied for quick reuse. Regenerate derivatives after source edits.

The separate artwork folder carries additional original asset variants, including accessories. These extracted files document the exact garment shapes used by the current renderer; changing a standalone file does not automatically rewrite the inline renderer paths.
