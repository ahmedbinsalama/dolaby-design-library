# حركة الويب

افتح index.html من خادم المعاينة المحلي. لا يبدأ المشهد تلقائيًا؛ Play يعيد الساعة، Pause يثبتها، Skip يعيد الاسم الكامل. شريط الزمن يتيح فحص اللقطات ويوقف التشغيل. تغيّر اللغة موضع الكتلة فقط.

المصدر منفصل HTML/CSS/JS؛ Do وLaby نصان حيان، والحلقة مسار SVG. ملف SVG للشخصية قابل للتحرير. الحركة تحكي العلامة وليست مؤشر انتظار. لا ينفذ هذا العرض استماعًا أو معالجة.

فحص التوقيت متاح أيضًا بمعامل مثل ?t=3.2؛ سجّل لقطة فعلية وقراءة DOM قبل وصف أي بند بأنه مختبر.
