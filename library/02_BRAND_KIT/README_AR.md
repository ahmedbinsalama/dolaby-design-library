# حزمة الهوية — الإصدار 1.0.0

كتاب الهوية موجود فعليًا في booklet/brand-book.pdf: 17 صفحة تشمل الغلاف و16 موضوعًا. مصدره القابل للتحرير هو brand-book.html مع brand-book.css وbrand-book.md. عدّل المصدر ثم أعد تصدير PDF وفحصه قبل المشاركة.

التطبيقات الثلاثة مستقلة داخل applications: واجهة تعريفية، وعرض إطلالة، وغلاف اجتماعي. توجد عينات حيّة للخط والألوان والرموز والاستخدامات الخاطئة. يربط asset-index.json عائلات الأصول B01–B16 بمصادرها.

مصادر الشعار وشخصية Laby المشتركة في 01_SHARED_FOUNDATIONS هي المرجع. التصديرات الشفافة والعاجية والأيقونات داخل logo-exports، وتصديرات الشخصية داخل laby-model-and-states/exports. يمكن تحرير ملفات SVG كمسارات متجهية؛ احتفظ بنسبة الحلقة وألوان الهوية المقفلة.

motion-web-demo هو مصدر حركة ويب فعلي مع التشغيل والإيقاف والتخطي والحالة الثابتة. تقليل الحركة موجود في المصدر؛ اختبار تفضيل النظام نفسه لم يُنفّذ. لم يُنشأ نموذج 3D أو ملف Figma أصلي. تفاصيل الاختبارات والفجوات في 05_QA.
