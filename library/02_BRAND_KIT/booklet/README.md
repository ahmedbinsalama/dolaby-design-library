# تحرير الكتاب

افتح brand-book.html للقراءة أو عدّل النصوص والصور في HTML؛ brand-book.css يحكم التخطيط والطباعة. صيغة الطباعة A4 أفقي، 17 صفحة: غلاف و16 موضوعًا. PDF تصدير للقراءة يُنشأ ويُفحص من هذا المصدر، ولا يحل محل HTML/CSS أو Markdown. أعد التصدير بعد تغيير المصدر.

كل الصور داخل المصدر أصول SVG حقيقية منفصلة، والنص حي قابل للبحث. الخطوط محلية بمسارات نسبية. لا توجد صفحات كاملة مفلطحة أو صورة كتاب تستبدل المصدر.
