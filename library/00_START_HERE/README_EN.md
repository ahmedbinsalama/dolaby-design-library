# DoLaby Complete Kits 1.0.0

Open `index.html` in this folder. Preserve the complete directory structure. The deliverables are actual editable HTML, CSS, JS, SVG and JSON sources, a searchable PDF, and raster exports. No native Figma or Canva file, or 3D model, was created.

1. Open the library and choose the brand book, UI prototype or Social editor.
2. In the Social editor, choose a template, language and blank variant. Edit the text or replace its illustration. Save edited HTML inside `04_SOCIAL_KIT` so its relative links resolve.
3. Keep a copy of the source. Existing PNG/JPG exports are in `04_SOCIAL_KIT/exports`; saving HTML does not automatically generate a new PNG.

Optional local preview: run `python3 serve.py` from the package root, or open `START_PREVIEW.command` on macOS. Visit http://127.0.0.1:8765/00_START_HERE/index.html. This requires Python3 and serves local static files only.

The prototype uses synthetic data and session-only state. No production backend, AI service, authentication or store connection is implemented. Instagram dimensions remain provisional; TikTok checks are limited to a specific advertising surface. See `known-limitations.md` and `05_QA` for the exact scope. No publishing or account changes occurred.

For resumption and source status, read `PRODUCTION_STATUS.json`. See `namespaces.md` for object-qualified identifiers.


Engine handoff: ../06_ENGINE_HANDOFF/index.html. Individual reusable assets: asset-library.html.
