# قراءة سجل المتطلبات

يضم `requirement-completion.csv` المتطلبات الأصلية الـ122 مع وجهتها في التسليم وحالة إنتاجها ودليل الفحص المحدود.

- `status`: حالة المتطلب كما وردت في حزمة المصدر، ومنها `REQUIRED_TO_PRODUCE`. هذا حقل تاريخي لا يصف حالة التسليم الحالية.
- `production_status`: حالة الإنتاج أو الاختبار لهذه النسخة.
- `target_family`: مسار موجود داخل الحزمة. يربط فهرس الأصول أو المكونات التفاصيل بمعرّفها الأصلي.
- `specification`: مرجع داخل حزمة التنفيذ الأصلية v1.1؛ لا يعني أن ملف المرجع الأصلي أعيد توزيعه داخل هذه الحزمة.
- `acceptance_evidence`: موضع الدليل ونطاقه. إنشاء المصدر، ونجاح اختبار محدود، وقبول المستخدم ثلاثة أمور مستقلة.

تحفظ الفحوص غير المنفذة حالتها الصريحة. لا يعني وجود ملف أو نجاح فحصه أن المنتج منشور أو أن الطلب السوقي مثبت.
