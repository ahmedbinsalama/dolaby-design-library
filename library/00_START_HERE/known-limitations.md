# حدود التسليم الفعلية

1. **المصدر المحلي هو نسخة التحرير المسلّمة.** لم تُنشأ ملفات أو قوالب أصلية في Figma أو Canva؛ توجد خرائط للنقل. لم يُفحص توفر الخدمة الأصلية من جديد، ولا يُقدَّم HTML على أنه ملف `.fig`.
2. **Laby مصدر متجهي ويب مبسّط.** توجد قياسات ومشاهد وحالات متجهة، ولا يوجد نموذج ثلاثي الأبعاد أو هيكل تحريك أو ضمان تطابق مع رندر المرجع. مواصفات3D السابقة مقترحات غير منفذة.
3. **النموذج التفاعلي يستخدم محاكاة محلية.** لا يتصل بمحرك ذكاء اصطناعي أو متجر أو بريد أو مصادقة حقيقية. تُصفّر الحالة عند إعادة التحميل أو Reset. أدوار الإدارة تصميمية وليست ضوابط أمنية منفذة.
4. **البيانات أمثلة مصطنعة.** أسماء المنتجات وأسعارها ليست عروضًا فعلية. لا توجد شراكات أو عمولات أو نتائج استخدام مثبتة. استُبعدت الصور المرجعية مجهولة الحقوق من الأصول النهائية، والرسوم المسلّمة متجهات أصلية لهذه المهمة. تتضمن الحزمة رخص الخطوط OFL.
5. **اختبارات الإتاحة محدودة النطاق.** لا شهادة مطابقة WCAG، أو بحث استخدام، أو اختبار أجهزة فعلية. لا يزال التكبير وقارئ الشاشة وتعدد المتصفحات غير مختبر. يوضح `05_QA/acceptance.csv` النتائج وحدودها؛ أما فحوص العرض عند320 و1024px فقد نُفذت كما هو موثق.
6. **حدود المنصات لم تُحسم بالكامل.** أعادت صفحة مساعدة Instagram الرسمية استجابة429، لذلك تظل المقاسات والقص مؤقتة. تحقق TikTok محدود بمواصفات إعلانات in-feed محددة. مناطق الأمان أدلة محافظة قابلة للإخفاء، ولا تضمن عدم تغطية المنصة للمحتوى.
7. **تحتاج التعديلات إلى إعادة تصدير وفحص.** حفظ HTML لا يولّد PNG أو قالب Canva. المثال المحفوظ المرفق يثبت دورة تعديل وحفظ وإعادة فتح واحدة. لا توجد مواد طباعة نهائية أو قيم Pantone/CMYK.
