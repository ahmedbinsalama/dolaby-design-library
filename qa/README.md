# فحوص موقع المكتبة

هذه فحوص تنفيذ محلية، وليست شهادة إتاحة أو بحث استخدام مستقلًا.

- static-checks.json: روابط ومصادر الحزمة وفهرس الشاشات والقوالب؛ لا ملفات مفقودة.
- responsive-browser.json:36 حالة للصفحات الـ12 عند 390/768/1440، و8 حالات حدّية عند 320/1024. احتُفظ بملاحظتي قراءة مقاس قديم مع إعادة فحص منفصلة ناجحة.
- interaction-checks.json: البحث والفلاتر والتنزيل والمعاينات والحفظ والتنقل وقارئ الأدلة.
- download-verification.json: قراءة ملف SVG المحمّل ونسخة HTML المعدّلة الفعلية.
- save-control-layout.json: زر الحفظ الجديد داخل عارض القوالب عند 320/768/1440.
- final-touch-targets.json: إعادة فحص أزرار التنزيل وحفظ القالب عند 320 بعد آخر تعديل للتنسيق؛ مساحة اللمس 44 بكسل ولا تمرير أفقي للصفحة.

الاختصار Meta+K لم يكتمل اختباره عبر أداة لوحة المفاتيح؛ النقر وEscape استُخدما بالفعل. لا مصفوفة كاملة لقارئ الشاشة والتكبير والأجهزة والمتصفحات. فحوص الحزمة الأصلية محفوظة مستقلة داخل library/05_QA بحدودها وتواريخها.
