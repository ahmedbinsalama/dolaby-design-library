# بنية الموقع ومصادره

الإصدار1.0.0 — مكتبة DoLaby متعددة الصفحات، عربية أولًا، ومصممة على ثوابت الهوية المرفقة.

## البنية

- `site-src/`: قوالب محتوى الصفحات، المصدر الأساسي لـHTML.
- `scripts/build.py`: تجميع الهيدر والفوتر والقوالب وإنتاج الصفحات والفهرس من الملفات الفعلية.
- `assets/site.css`: تخطيط متجاوب وخطوط وألوان وتركيز وحالات واجهة، مع الرجوع لأسس الحزمة المشتركة.
- `assets/site.js`: البحث والفلاتر وتفاصيل الملفات وقراءة الأدلة ومعاينات المصادر والتنزيلات.
- `data/catalog.json`: فهرس مشتق يتضمن مسارات الملفات وحجومها وبصماتها، والمكونات والشاشات والقوالب.
- `data/catalog.js`: رفيق مشتق لتصفح الفهرس من ملفات محلية دون تحميلJSON منفصل.
- `library/`: الحزمة924ملفًا، محفوظة كما سُلّمت، دون إعادة تحرير مصادرها.
- `downloads/`: الحزمة القابلة للتنزيل وسجل سلامتها.
- `qa/`: فحوص الموقع الجديد، منفصلة عن فحوص مصادر الحزمة التاريخية.

## الصفحات

الرئيسية ← الهوية / الأصول / الواجهات / المحتوى / المحركات / الأدلة / التنزيلات. تفاصيل الملف ترتبط بمصدره ونسخه المرتبطة. المعاينة الحية تضم ملفHTML من قائمة الفهرس الموثوقة داخلiframe، وتسمح بتغيير العرض وفتح الأصل. قارئ الأدلة يهربHTML ويقيّد بروتوكولات الروابط قبل عرضMarkdown.

لا يعتمد النشر على مسارات تبدأ بشرطةجذرية؛ الملفات تعمل تحت مسار مستودع GitHub Pages. لا حسابات أو تحليلات تتبع أو اتصالات خدمةAI. نسخ الألوان والمسارات يستخدم الحافظة المحلية عند دعم المتصفح.

## التعديل

عدّل القالب أوCSS أوJavaScript، ثم نفّذ `python3 scripts/build.py` و`python3 scripts/check.py`. لا تعدّل الصفحات الناتجة وتتوقع بقاء التغيير بعد البناء. ملفات الحزمة المحفوظة لها بصمات مستقلة؛ إذا احتجت تعديل الحزمة فأنشئ إصدارًا جديدًا بدل كسر النسخة المجمدة.

## التنزيل

روابط الملفات الفردية تشير إلى ملفات حقيقية. معاينة HTML لا تعني استقلال الملف عن خطوطه وأصوله؛ الحزمة الكاملة هي طريقة التشغيل والتحرير المحلي الموصى بها. تنزيل مصدر الموقع من GitHub يتضمن مصادر البناء والملفات الملتزم بها في الفرع الرئيسي.

## حفظ التعديلات من العارض

زر حفظ تعديلات HTML في عارض القوالب يقرأ المصدر المضمّن نفسه، ويحفظ النص الحالي والصورة المختارة، ويزيل أدوات المحرر والسكربتات من النسخة المحفوظة. ضع الملف داخل مجلد 04_SOCIAL_KIT من الحزمة المحلية للحفاظ على التبعيات. الحفظ لا يولّد PNG أو ينشر المحتوى.

الفهارس داخل data مشتقة من الملفات؛ لا تضمّن بصمة الفهرس أو حجمه داخل ذاته، لتجنب المرجع الدائري. الفهرس يشمل ملفات الموقع والحزمة والتنزيلات والفحوص، مع استثناء بيانات Git والمخرجات المؤقتة.
